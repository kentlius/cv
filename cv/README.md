# CV

This folder contains the canonical CV content for Kent Liusudarso, managed as a
Python package and rendered to PDF via [RenderCV](https://rendercv.com).

## Structure

```
cv/
├── Kent_Liusudarso_CV.yaml   # canonical CV input (edit this)
├── pyproject.toml            # uv-managed; depends on rendercv[full]==2.8
├── README.md                 # generated by rendercv (committed)
└── rendercv_output/          # generated PDF/PNG/HTML/Markdown (gitignored)
```

## Local render

```sh
# from the repo root
uv sync --package cv
uv run --package cv rendercv render Kent_Liusudarso_CV.yaml
```

The rendered PDF will be written to `Kent_Liusudarso_CV/` (RenderCV's default
output folder) or, when invoked with `--output-path rendercv_output`, to
`rendercv_output/`. The GitHub release workflow uses the latter.

## Editing

Edit `Kent_Liusudarso_CV.yaml`. Push to `main` and the `Render a CV` workflow
will re-render and (when output content changes) auto-commit the updated
`README.md` and Typst source back to `main`. Pushing a `v*` tag triggers the
`Release a CV` workflow, which attaches the rendered PDF to a GitHub release.
